# Sri Lanka Climate & Risk Analytics Dashboard

An interactive data analytics dashboard developed to explore climate patterns and climate-related risks across districts in Sri Lanka.

## Features

- National Climate Overview
- District-Level Climate Analysis
- Heat and API Risk Analysis
- Drought Analysis
- Precipitation and Flood Analysis
- Interactive 7-Day Weather Forecasting
- Methodology and Model Information

## Technologies Used

- Python
- Pandas and NumPy
- Streamlit
- Plotly
- Scikit-learn

## Project Files

- `app.py` – Main Streamlit dashboard application
- `forecast.py` – Forecasting functionality
- `forecasts_7days.parquet` – Forecast data

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```

## Note

This project is developed for educational and analytical purposes. Forecasts and climate-risk indicators should be interpreted with the limitations described in the dashboard.
